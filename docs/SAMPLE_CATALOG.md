# ร้านค้าและหมวดหมู่ของข้อมูลตัวอย่าง

มี 20 ร้าน ร้านละ 25 สินค้า รวม 500 สินค้า ครอบคลุม 20 หมวด
แต่ละร้านมี 1–3 หมวดที่เกี่ยวข้องกับแนวร้าน ไม่จำเป็นต้องขายครบทุกหมวด

ไฟล์ data.sql สร้างข้อมูลแบบนี้ตั้งแต่ต้น ส่วนฐานเก่าใช้ migrations/003_theme_sample_merchants.sql ใน transaction
